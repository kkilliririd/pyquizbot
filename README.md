# pyquiz bot

чат-бот для тестирования знаний по python / python білімдерін тексеруге арналған чат-бот

## технологии / технологиялар

- python 3.10+
- django 4.2+
- sqlite3
- bootstrap 5

## структура проекта / жоба құрылымы

```
pyquizbot/
├── manage.py
├── requirements.txt
├── README.md
├── db.sqlite3
├── config/
│   ├── settings.py
│   ├── urls.py
│   └── wsgi.py
└── quizbot/
    ├── models.py        ← модель результатов / нәтижелер үлгісі
    ├── views.py         ← логика / логика
    ├── urls.py          ← маршруты / маршруттар
    ├── questions.py     ← вопросы / сұрақтар
    └── templates/
        └── quizbot/
            ├── base.html
            ├── home.html
            ├── question.html
            ├── results.html
            └── history.html
```

## установка / орнату

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## запуск / іске қосу

```
http://127.0.0.1:8000/
```

## функции бота / бот функциялары

- выбор темы и режима теста / тақырып пен режим таңдау
- вопросы с подсказками / кеңестері бар сұрақтар
- мгновенная обратная связь / жедел кері байланыс
- результаты с разбором ошибок / қателерді талдаумен нәтижелер
- история результатов в бд / дб-дағы нәтижелер тарихы

## обработка ошибок / қателерді өңдеу

- пустое имя → значение по умолчанию / бос атау → әдепкі мән
- неверный режим → редирект на главную / қате режим → басты бетке
- пустая сессия → редирект / бос сессия → редирект
- некорректный ответ → обработка через try/except
